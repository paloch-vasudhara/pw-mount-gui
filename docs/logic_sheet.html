G Global rules

Apply app-wide and are enforced by the mount gateway, regardless of UI state.

IDRule
G1Limits. Lim EL = station limiting elevation (Settings › Hardware), 0–90°, default 15°. Sun keep-out = 15° disc (fixed; OTA FOV ≈ 3°). Sun distance is "safe" when > 15°.
G2Sun check runs continuously in every mode — slew, goto, jog/step, sidereal track, object track and pre-position wait. If a planned path crosses the disc, the operation is re-routed around it to the other side of the path via a generated custom path (planner design D-SUN).
G3Limit reached (Lim EL or Sun disc, any mode) → mount becomes STOPPED and any operation that would push past the limit is disabled. Exception: starting a Track Object workflow may pre-position while the object is between 0° and Lim EL (A1d).
G4Disconnection = stop. If the app loses its link to the gateway, the gateway stops the mount immediately (slews, jogs, tracks). After reconnection the mount stays STOPPED; nothing resumes automatically.
G5One object may be tracked at a time.
G6Live data only — decayed objects are excluded from every search, list and viewer.
G7Every disabled control or refused command reports its reason on the relevant status line (e.g. "below station limit elevation", "within 15° of the Sun", "PWI4 not running").
G8Mount states: STOPPED SLEWING incl. jog/step TRACKING incl. pre-position wait HOMING BUSY connect/disconnect sequence FAULT DISCONNECTED incl. PWI4 not running
Known limit (G4): if the gateway process itself dies, nothing can send the stop. The app shows a warning that hands the user off to PWI4 (which stays open) to stop the operation there. Start-up stop: whenever the gateway starts (incl. after a crash) and finds the mount moving — slewing, tracking, following a path/TLE or an active offset rate — it stops the mount before anything else (PWI4 has no watchdog).

TRACK OBJECT button is active when ALL hold

  • the object is above the actual horizon (0°);
  • its current pass rises above Lim EL (not a pass that peaks below Lim EL, not an object already setting below Lim EL);
  • it is not within 15° of the Sun.

Otherwise disabled, with the reason shown. A1c: with nothing selected the section shows "No object selected".

A1d Object tracking workflow run by the gateway

  1. Check the pass: above 0° (or below 0° with its Lim EL crossing at most 5 min ahead), reaches above Lim EL; Sun check (G2).
  2. If still below Lim EL: compute the Lim EL crossing point, slew there and wait — status TRACKING, card shows a countdown.
  3. At the crossing time, hand the object to PWI4 (follow_tle for satellites; custom path for aircraft).
  4. End of path: tracking stops at Lim EL (G3); mount becomes STOPPED.

Can be started from: the Track Info card · Track Target modal (satellite) · Pass Analysis [Track].

A2b-i Satellite Pass Analysis Pass Analysis.png

  • Station fixed to the Settings location; limiting elevation = Lim EL. Interval is start–end (H1).
  • Mode OPTICALLINE OF SIGHT — Optical lists Visible Duration (actually visible: above Lim EL, illuminated, and the Sun below the horizon at the observer); LOS lists Duration.

A3 Sky Viewer

Live local hemisphere viewed upward (East on the left). Blue separated circle = current mount pointing. Clock below the chart; its Time UTC/Local Time tag toggles the display (local = Settings timezone).

A3a · Sky chart

  • Satellites computed in 30-min chunks, one layer per orbit class (LEO / MEO / GEO); cached; next chunk computed in the background when 10 min remain and appended; expired data evicted.
  • Hidden classes are still computed (they may be toggled on at any time).
  • No item limit → performance work required (vectorised propagation, one canvas layer per class, per-class cadence).
  • Below Lim EL: objects dimmed; dashed ring marks the limit.
  • Sun and Moon drawn (Planetary Bodies). Stars without labels.
  • Select → Track Info + focused mode; current position highlighted only (no path). Deselect via ✕ on the card or clicking anywhere that is not an object.
Two changes from ssa-toolkit (to be applied back there later): hovering a label does not show the object's data; the hovered object is the one closest to the pointer, not the one on top.

A5b Pointing mode

STOPPEDTRACK   STOPTRACKING

  • STOP — stops any tracking (incl. object tracks), holds the az/el of the moment.
  • TRACK — tracks the sidereal coordinates of the moment; disabled below Lim EL or inside the Sun disc.

(iii) Jog Job Modal.png

ModeBehaviour
JOGTurns at the chosen speed while a direction is held. Speeds 0.5 / 1.0 / 2.0 / 5.0 / 10.0 °/s (default 5.0) via −/+ stepper.
STEPOne step per press: 1′ / 5′ / 10′ / 30′ / 1° (default 10′). Further steps are blocked until the current one completes.

InputAz/El boxes read-only live values. Arrow keys: hold = jog, press = one step.

(iv) Go To Goto Modal.png

  • Local Az/El → ends STOPPED; Celestial RA/Dec (J2000) → ends TRACKING.
  • Both checked against Lim EL and the Sun disc; invalid → elevation box(es) red and the command disabled.
  • Local Elevation box capped 0–90° (scroll cannot go below 0°).
  • Allowed during an object track (replaces it).

H Helpers & utilities

IDHelper
H1Datetime suite — as ssa-toolkit: [YYYY]-[MM]-[DD] [hh]:[mm]:[ss] + picker; seconds precision; picker button same height as the fields.
H2Angular triads — as ssa-toolkit incl. cardinal chip, ± chips, scroller, caps and typing limits; use the LEGACY version where the Nuxt port lacks chip behaviour. Same format selector/transforms, extended to altitude FT/M/KM.
H3Aircraft predictor (planned) — Kalman filter, gain tuning required. Not in the first build.
H4Local ↔ J2000 transform for the Settings location at an explicit time: Goto passes now, IOD passes the row epoch.
H5Sun avoidance path planner (D-SUN) — detour around the 15° disc for slews and object tracks (G2).

Formatting & scope

  • Font: renders use Bahnschrift; the build uses Barlow (web-embeddable, OFL).
  • Thousand separator: a single space (e.g. 36 540 km).
  • Out of scope for now: camera control (astrometry from uploads only), aircraft tracking (H3 / ADS-B), satellite paths in the Sky Viewer, tracking IOD results.
