# Country flags (local)

4:3 SVG flags from the `flag-icons` npm package v7.2.3 (MIT, see `LICENSE.txt`), copied verbatim
from `flags/4x3/`. File name = lowercase ISO 3166-1 alpha-2 code (`th.svg`, `us.svg`, `eu.svg`, ...).

Used by `app/components/track/FlagBadge.vue` via `app/utils/country-flag.ts` (DB owner code → ISO).
Served locally so the mount PC makes no outside requests and works offline. Edit or replace any
file freely; keep the file name.
